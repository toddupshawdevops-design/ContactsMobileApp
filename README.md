# Contacts Mobile App
**Student:** Todd Upshaw

A simple Android contacts app with two A-name contacts:
- Ava Anderson
- Aaron Adams

Each contact has a separate details Activity and XML layout. The main screen opens each detail screen, and each detail screen returns to the contact list.

## Open in Android Studio
1. Extract the project ZIP.
2. In Android Studio, choose **Open** and select the `Todd_Upshaw_ContactsMobileApp` folder.
3. Allow Gradle sync to finish.
4. Start an Android emulator and click **Run**.

## GitHub
Create an empty GitHub repository named `ContactsMobileApp`. In Android Studio, use **VCS > Enable Version Control Integration > Git**, then commit and push the project.
